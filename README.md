# Engineering Graduate Salary Prediction Dashboard

## Project Overview

This project uses Microsoft Excel 365 to analyze engineering graduate salary data and explore salary trends across different categories.

## Tools Used

- Microsoft Excel 365
- PivotTables and PivotCharts
- Slicers and Interactive Filters
- Data Cleaning and Data Visualization

## Key Features

- 8 KPI cards for key metrics
- Salary analysis by specialization, degree, and gender
- College tier and state-wise salary comparisons
- Graduation year and salary category analysis
- Interactive slicers for filtering and exploring data

## Dataset

The project analyzes 2,997 engineering graduate records.

## Objective

To identify salary patterns and understand how factors such as specialization, degree, college tier, and location relate to graduate salaries.
